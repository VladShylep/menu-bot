# 🍲 menu-bot — Telegram-бот «Меню й закупи»

Бот живе в Telegram-групі двох людей і:

- складає **меню на 7 днів** (3 прийоми їжі, 2 людини, готуємо раз на 2–3 дні великими порціями), враховуючи запаси й улюблені страви;
- веде **запаси вдома**: розуміє вільний текст «купив гречку», «закінчився рис», «вдома є 10 яєць» і записує, хто що купив;
- дає **список покупок за відділами в порядку магазину Biedronka** (`/buy`);
- **щоранку сам рахує** (кодом, без LLM), чого забракне за меню на найближчі 1–2 дні, і пише в групу «сьогодні варто скупитись, йдете?»;
- якщо продукт закінчився раніше, ніж мав за обліком, **збільшує норму споживання** цього продукту;
- відповідає на «що приготувати на вечерю?», «заміни борщ у четвер на плов», «додай страву…»;
- мовчить, якщо повідомлення не про їжу.

**Стек:** JavaScript (Node.js), [grammY](https://grammy.dev) (вебхук), Cloudflare Workers + Cron Triggers (безплатно), Google Sheets (база даних), Google Gemini API з function calling (безплатний тариф).

## Як це працює

```
Telegram ──вебхук──▶ Cloudflare Worker ──▶ grammY
                         │                  ├─ /menu, /buy, /stock … (код)
                         │                  └─ вільний текст ──▶ Gemini (function calling)
                         │                                         └─ інструменти: запаси, страви, меню, список
                         ├─ Cron щоранку ──▶ списання + прогноз ──▶ «варто скупитись?»
                         └─ Google Sheets (Запаси, Страви, Меню, Покупки)
```

- Усі розрахунки (меню − запаси, прогноз, списання, сортування за відділами) — детермінований код у `src/planner.js`, покритий тестами.
- LLM лише розуміє мову й викликає інструменти: оновити запаси, прочитати/зберегти меню, додати страву, скласти список.
- Нове меню зберігається як **чернетка** з кнопками «✅ Затвердити» / «🔄 Інше меню». Затвердити може будь-хто з двох. Прогноз і `/buy` рахуються тільки за затвердженим меню.
- Кожного ранку Cron списує із запасів продукти страв, які за меню готували вчора, і перевіряє, чи вистачить продуктів на найближчі дні.

### Команди

| Команда | Що робить |
|---|---|
| `/setup` | Створює вкладки в таблиці й заповнює стартову базу з 17 страв |
| `/menu [побажання]` | Складає меню на 7 днів, наприклад `/menu більше риби` |
| `/showmenu` | Показує поточне меню |
| `/buy` | Список покупок на тиждень за відділами Biedronka |
| `/stock` | Що є вдома |
| `/chatid` | Показує id чату (потрібно під час налаштування) |
| `/help` | Підказка |

### Таблиця Google Sheets

Бот сам створює вкладки командою `/setup`. Їх можна редагувати вручну.

| Вкладка | Колонки |
|---|---|
| **Запаси** | Продукт · Кількість · Одиниця (г / мл / шт) · Відділ · Коефіцієнт · Оновлено · Хто |
| **Страви** | Назва · Прийом · Інгредієнти на 1 порцію · Зберігається днів · Улюблена |
| **Меню** | Дата · Прийом · Страва · Готувати · Порцій · Статус · Списано |
| **Покупки** | Дата · Хто · Продукт · Кількість · Одиниця |

Інгредієнти пишуться через крапку з комою, на **1 порцію** (одна людина, один прийом): `гречка 80 г; курячі стегна 200 г; цибуля 0.3 шт; сіль`. Інгредієнти без кількості (сіль, спеції) у закупах не враховуються. Щоб страва вважалася улюбленою, впишіть «так» у колонку «Улюблена» (або напишіть боту «плов — улюблена»).

Порядок відділів Biedronka задається списком `BIEDRONKA_ORDER` у `src/departments.js`. Відділ продукту визначається автоматично за назвою, а якщо вписати його в колонку «Відділ» у «Запасах», бот візьме ваш варіант.

## Налаштування з нуля

Знадобиться приблизно 30–40 хвилин. Тобі потрібні: Node.js 20 або новіший ([nodejs.org](https://nodejs.org)), git і акаунти Telegram, Google й Cloudflare.

Команди нижче для PowerShell у Windows (у macOS/Linux вони такі самі, крім позначених).

### 0. Встановити залежності

```powershell
cd C:\Users\<ти>\Documents\projects\menu-bot
npm install
npm test        # має бути "pass" і жодного "fail"
```

### 1. Telegram-бот (@BotFather)

1. Відкрий [@BotFather](https://t.me/BotFather) → `/newbot` → придумай ім'я та username (має закінчуватися на `bot`).
2. BotFather дасть **токен** виду `123456789:AA...` — це `TELEGRAM_BOT_TOKEN`. Нікому його не показуй.
3. **Вимкни Privacy Mode**, інакше бот не бачитиме звичайних повідомлень у групі: `/setprivacy` → вибери бота → **Disable**.
4. (Необов'язково) `/setcommands` → вибери бота → встав:
   ```
   menu - скласти меню на тиждень
   showmenu - показати меню
   buy - список покупок
   stock - що є вдома
   setup - підготувати таблицю
   help - допомога
   ```
5. Створи групу з другою людиною й **після** вимкнення Privacy Mode додай туди бота. Якщо бот уже був у групі, видали його й додай знову: налаштування приватності застосовується під час додавання.

### 2. Ключ Gemini API (безплатно)

1. Відкрий [aistudio.google.com/apikey](https://aistudio.google.com/apikey) і увійди своїм Google-акаунтом (картка не потрібна).
2. Натисни **Create API key**. Якщо попросить вибрати проєкт, обери **Create API key in new project** (або наявний проєкт `menu-bot`).
3. Скопіюй ключ `AIza...` — це `GEMINI_API_KEY`. Нікому його не показуй.
4. За замовчуванням бот використовує модель `gemini-3.5-flash-lite` (змінна `GEMINI_MODEL` у `wrangler.toml`). Кожне повідомлення в групі йде в Gemini, щоб бот вирішив, чи воно про їжу. На безплатному тарифі діють ліміти запитів на хвилину й на день (актуальні значення дивись у [документації](https://ai.google.dev/gemini-api/docs/rate-limits) і в AI Studio); для групи з двох людей їх зазвичай вистачає. Якщо ліміт вичерпано, бот відповість помилкою, а за хвилину-дві знову запрацює. Також на безплатному тарифі Google може використовувати запити для покращення своїх продуктів: не пишіть боту нічого конфіденційного.

### 3. Google Sheets і service account

1. Відкрий [console.cloud.google.com](https://console.cloud.google.com) → вгорі **Select a project → New project** → назва `menu-bot` → **Create**.
2. **APIs & Services → Library** → знайди **Google Sheets API** → **Enable**.
3. **IAM & Admin → Service Accounts → Create service account** → назва `menu-bot` → **Create and continue** → роль не потрібна → **Done**.
4. Відкрий створений service account → вкладка **Keys → Add key → Create new key → JSON**. Завантажиться файл, наприклад `menu-bot-xxxx.json`. **Не клади його в папку проєкту** і нікуди не завантажуй (на всяк випадок `service-account*.json` є в `.gitignore`).
5. Створи нову таблицю на [sheets.google.com](https://sheets.google.com). Її id — це частина адреси між `/d/` і `/edit`:
   `https://docs.google.com/spreadsheets/d/`**`1AbC...xyz`**`/edit` → `SPREADSHEET_ID`.
6. У таблиці натисни **Share (Поділитися)** і додай email service account (поле `client_email` у JSON, виду `menu-bot@....iam.gserviceaccount.com`) з правами **Editor**.

### 4. Cloudflare Workers

1. Зареєструйся на [dash.cloudflare.com](https://dash.cloudflare.com) (план Free).
2. Увійди з термінала:
   ```powershell
   npx wrangler login
   ```
3. Задеплой Worker, щоб отримати адресу:
   ```powershell
   npm run deploy
   ```
   У виводі буде адреса виду `https://menu-bot.<твій-субдомен>.workers.dev`. Якщо wrangler попросить зареєструвати субдомен `workers.dev`, погодься.
4. Придумай секрет вебхука: 30–60 символів, тільки латиниця, цифри, `_` і `-`. Згенерувати в PowerShell:
   ```powershell
   -join ((48..57)+(65..90)+(97..122) | Get-Random -Count 40 | ForEach-Object {[char]$_})
   ```
5. Додай секрети (кожна команда попросить вставити значення):
   ```powershell
   npx wrangler secret put TELEGRAM_BOT_TOKEN
   npx wrangler secret put TELEGRAM_WEBHOOK_SECRET
   npx wrangler secret put GEMINI_API_KEY
   npx wrangler secret put SPREADSHEET_ID
   ```
   JSON-ключ Google передай файлом, щоб не зламати переноси рядків:
   ```powershell
   Get-Content C:\шлях\до\menu-bot-xxxx.json -Raw | npx wrangler secret put GOOGLE_SERVICE_ACCOUNT_JSON
   ```
   (macOS/Linux: `npx wrangler secret put GOOGLE_SERVICE_ACCOUNT_JSON < ~/шлях/menu-bot-xxxx.json`)

Секрети зберігаються в Cloudflare й ніколи не потрапляють у git.

### 5. Вебхук Telegram

Створи файл `.dev.vars` (він у `.gitignore`), скопіювавши `.dev.vars.example`, і впиши хоча б `TELEGRAM_BOT_TOKEN` і `TELEGRAM_WEBHOOK_SECRET` (ті самі, що в секретах). Потім:

```powershell
npm run webhook -- https://menu-bot.<твій-субдомен>.workers.dev
```

Скрипт зареєструє `https://.../webhook` із секретним токеном і перевірить, чи вимкнено Privacy Mode. Він також виведе JSON з інформацією про бота: його можна (необов'язково) зберегти як секрет `BOT_INFO`, тоді бот не робитиме зайвий запит `getMe` на кожне повідомлення.

### 6. Прив'язати бота до групи

1. Напиши в групі `/chatid`. Бот відповість id виду `-1001234567890`.
2. Збережи його:
   ```powershell
   npx wrangler secret put GROUP_CHAT_ID
   ```
   Після цього бот реагує тільки у вашій групі, а Cron знає, куди писати. Без `GROUP_CHAT_ID` бот відповідав би в будь-якому чаті, куди його додали, і витрачав би ваш безплатний ліміт Gemini.
3. Напиши `/setup`: бот створить вкладки й стартову базу страв.
4. Розкажи, що є вдома: «вдома є 2 кг картоплі, 1 кг рису, 10 яєць, пів кіло фаршу».
5. `/menu` → подивись чернетку → **✅ Затвердити** → бот покаже, що докупити.

Готово. Щоранку о 06:00 UTC (07:00 взимку й 08:00 влітку за Варшавою) бот перевірятиме запаси. Час змінюється в `wrangler.toml` → `[triggers] crons`.

## Налаштування (`wrangler.toml` → `[vars]`)

| Змінна | За замовчуванням | Що означає |
|---|---|---|
| `TIMEZONE` | `Europe/Warsaw` | Часовий пояс для дат меню |
| `PERSONS` | `2` | Скільки людей їсть |
| `FORECAST_DAYS` | `2` | За скільки днів наперед попереджати про нестачу |
| `GEMINI_MODEL` | `gemini-3.5-flash-lite` | Модель Gemini |

Секрети (через `wrangler secret put`, або в `.dev.vars` для локального запуску): `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET`, `GROUP_CHAT_ID`, `GEMINI_API_KEY`, `SPREADSHEET_ID`, `GOOGLE_SERVICE_ACCOUNT_JSON`, необов'язково `BOT_INFO`.

Після зміни `wrangler.toml` виконай `npm run deploy` ще раз.

## Розробка

```powershell
npm test                      # юніт-тести логіки + наскрізний тест бота з підробленими API
npx wrangler tail             # живі логи задеплоєного Worker
npx wrangler dev --test-scheduled   # локальний запуск (секрети беруться з .dev.vars)
```

Перевірити ранковий Cron локально: при запущеному `wrangler dev --test-scheduled` відкрий у браузері `http://localhost:8787/__scheduled?cron=0+6+*+*+*`.

### Структура

```
src/
  index.js        точка входу Worker: вебхук + Cron
  bot.js          команди, кнопки, вільний текст (grammY)
  agent.js        Gemini API з function calling: системний промпт та інструменти
  service.js      операції над даними: запаси, страви, меню, прогноз, ранкова перевірка
  planner.js      чиста логіка: меню → потреби → нестача → список (без мережі)
  store.js        вкладки й колонки Google Sheets
  sheets.js       REST-клієнт Google Sheets із JWT service account (WebCrypto)
  units.js        розбір і нормалізація кількостей (кг → г, л → мл)
  departments.js  відділи Biedronka та їх порядок
  dates.js        дати в часовому поясі групи
  seed.js         стартова база страв
scripts/set-webhook.mjs   реєстрація вебхука
test/                     тести (node:test)
```

### Обмеження MVP

- Бот не пам'ятає попередніх повідомлень. Щоб уточнити, відповідай (reply) на його повідомлення: текст, на який відповідаєш, передається в контекст.
- Продукт у запасах і в рецептах має збігатися назвою й одиницею (г / мл / шт). Бот просить LLM писати назви однаково й попереджає, якщо одиниці не збігаються. Розбіжність можна виправити прямо в таблиці.
- Списання за меню відбувається автоматично. Якщо щось не готували або з'їли більше, просто напишіть боту («борщ не варили», «вдома лишилось 300 г гречки»).

## Як запушити на GitHub

1. На [github.com/new](https://github.com/new) створи **порожній** репозиторій `menu-bot` (без README, .gitignore і ліцензії), бажано Private.
2. У папці проєкту:
   ```powershell
   git status                 # переконайся, що .dev.vars і JSON-ключів немає в списку
   git remote add origin https://github.com/<твій-логін>/menu-bot.git
   git push -u origin main
   ```
   Якщо git попросить увійти, з'явиться вікно входу GitHub (Git Credential Manager), або використай [Personal Access Token](https://github.com/settings/tokens) замість пароля.

Секрети в репозиторій не потрапляють: вони живуть у Cloudflare (`wrangler secret`) і в локальному `.dev.vars`, який є в `.gitignore`.
